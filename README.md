# 🏪 Mini PoS System

Sistem Point of Sale sederhana berbasis PHP Native + MySQL.

## ✨ Fitur
- 🛒 Kasir dengan keranjang belanja
- 📦 Manajemen produk & inventory
- 📊 Mutasi stok (restock, adjustment)
- 🖨️ Cetak struk thermal
- 🔐 Login multi-role (Admin & Kasir)

## 🚀 Cara Install
1. Clone repository ini
2. Buat database dengan menjalankan `setup.sql`
3. Konfigurasi koneksi di `config/database.php`
4. Akses `http://localhost/mini-pos`

## 🔑 Login Default
- Admin: `admin` / `admin123`
- Kasir: `kasir1` / `kasir123`

## 🛠️ Teknologi
- PHP 8.x
- MySQL
- Bootstrap 5
- JavaScript Vanilla
